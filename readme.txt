== Description ==

ContentCrafter AI is a comprehensive WordPress plugin that integrates with OpenAI's ContentCrafter API to generate high-quality content for your WordPress site. Create engaging blog posts, pages, and custom post types with just a few clicks.

= Key Features =

* **AI-Powered Content Generation**: Generate blog posts, pages, and custom post types using ContentCrafter
* **Smart Title Generation**: Automatically generate compelling titles for your content
* **Category Selection**: Choose categories for generated posts
* **Multiple Post Types**: Support for posts, pages, and custom post types
* **HTML Cleanup**: Automatic formatting and cleanup of generated content
* **Gutenberg Block Support**: Optional integration with WordPress block editor
* **Elementor Integration**: Seamless integration with Elementor page builder
* **Avada Theme Integration**: Automatic font weight application for Avada theme posts
* **Shortcode Support**: Display generated content anywhere with `[contentcrafter_output]`

= Modern Admin Interface =

* Clean, professional design with intuitive controls
* Real-time preview of generated content
* Tabbed output (Preview, HTML, Shortcode)
* Copy to clipboard functionality
* Responsive design for all devices

= Advanced Settings =

* API Configuration with secure OpenAI API key management
* Model Selection (GPT-3.5 Turbo, GPT-4, GPT-4 Turbo)
* Token Control (adjust max tokens and temperature)
* Post Status Options (Draft, Published, Private, Pending Review)
* Usage Statistics to track your content generation activity

= Technical Features =

* Security Best Practices with proper sanitization and nonce verification
* Comprehensive error handling and validation
* AJAX Integration for smooth, asynchronous content generation
* Custom Post Type Support
* Avada Theme Integration with automatic font weight application

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/contentcrafter-ai/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to 'ContentCrafter' → 'Settings' to configure your API key

== Frequently Asked Questions ==

= How do I get an OpenAI API key? =

Visit [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys) to create an account and get your API key.

= Which OpenAI model should I use? =

* **GPT-3.5 Turbo**: Fast and cost-effective (recommended for most use cases)
* **GPT-4**: More capable but higher cost
* **GPT-4 Turbo**: Latest model with improved performance

= Can I use this with Elementor? =

Yes! ContentCrafter AI includes full Elementor integration. When enabled, generated content is automatically converted to Elementor widgets and sections.

= Does this work with custom post types? =

Yes, the plugin supports all registered post types including custom post types.

= Is my API key secure? =

Yes, your API key is stored securely in the WordPress database and is never exposed in the frontend.

= Can I preview content before publishing? =

Yes, you can preview generated content in the admin interface before creating a WordPress post.
